## How I use it

1. Open a page and click a problem.
2. Solve it. Save the code in `solutions/` or use a submission link.
3. Change `- [ ] Solved` to `- [x] Solved`, then replace `_not added yet_` with the link.
4. Push. The workflow updates the icons and the tables above.

To update by hand: `python scripts/sync_progress.py`

## Notes

- `~` before a number means the difficulty is my estimate, not a Codeforces rating.
- Problem data: `data/problems.csv`. The page list: `data/pages.json`.
